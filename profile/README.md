<p>把咨询里出现频率最高的问题原话摘出来，其实就这么几句："今天付今天能用吗"、"你说的纯净到底怎么验"、"路不通谁来管"、"早上还好好的下午就掉线，算谁的问题"、"售后是不是卖完就不管了"。这五个问题串起来正好是一条完整的交付链：开通、验收、故障、兜底、跟进。下面按顺序一个个答，答的都是可以当场验证的动作，不是承诺。</p>

<h2>一、"今天付今天能用上吗"</h2>
<p>能，但"能用"分三层：拿到地址算第一层，环境配好算第二层，能稳定跑完一轮完整操作算第三层。多数纠纷出在对"能用"的定义不一致——卖方说交付完成，你说还是用不了。</p>
<h3>从下单到可跑要经过四步</h3>
<p>下单确认地区与条数、从资源池分配地址、生成环境配置、交付地址与配置文件。自营池子这四步在两到四小时内能走完；如果对方说要"向上游申请"，那就不叫当天开通，叫当天申请。</p>
<h3>当天开通后先做三分钟自检</h3>
<p>查 ASN 是否为运营商、测一次目标站点连通、确认时区与出口城市一致。三分钟能过，说明交付层没问题；三项里有一项不过，当天就该提工单，不要留到第二天。</p>

<h2>二、"纯净"到底指什么</h2>
<p>这个词没有统一定义，所以要拆成可验证的指标：段类型、历史记录、同段邻居、当前是否在公开名单里。四项都能验，才谈得上纯净。</p>
<h3>四项验收指标与判据</h3>
<p>段类型看 ASN 归属；历史记录看该段是否长期被用于高投诉类业务；同段邻居看同 /24 已售条数与客户类型；公开名单看主流查询站是否有记录。四项里最容易做假的是第一项，最容易忽略的是第三项。</p>
<h3>自己动手验的方法</h3>
<p>whois 查 orgname，ipinfo 查 ASN，traceroute 看路径形态，再用两三个公开查询站交叉看记录。全部动作十分钟内能完成，不需要任何付费工具。验完把结果存进验收表，作为后续对比基线。</p>

<h2>三、"路不通"分几种，分别找谁</h2>
<p>"不通"是个笼统描述，实际至少有四种：完全连不上、能连但很慢、能连但目标站点拒绝、只有某些功能不可用。四种的责任方完全不同，找错人只会浪费时间。</p>
<h3>四种情形与责任划分</h3>
<p>完全连不上，先查本机 DNS 与路由，再查地址是否被上游封禁；能连但慢，看是否为晚高峰拥塞，属线路容量问题；目标站点拒绝，多半是段信誉或请求特征问题；功能不可用，通常是环境参数不一致。前两种找卖方，后两种先自查。</p>
<h3>提工单要带的三样东西</h3>
<p>出问题的地址与时间点、复现命令与输出、已做过的排查动作。三样齐了，对方能直接定位；只说"用不了"，来回沟通就要耗掉半天。建议把这三样做成模板，出问题直接填。</p>

<h2>四、"环境掉线"为什么更难查</h2>
<p>线路掉线至少有明确的现象——连不上。环境掉线往往是"能用但不对"：页面能开、登录能过，但订阅页地区错了，或者一直提示验证。这类问题没有报错，只能靠对比发现。</p>
<h3>环境掉线的三种典型表现</h3>
<p>一是地区显示与出口不符，二是环境参数在重启后被重置，三是配置文件之间发生参数串用。前两种是配置管理问题，第三种是隔离没做到位。三种都不属于线路故障，找卖方解决不了。</p>
<h3>自查顺序：先比参数，再比行为</h3>
<p>把当前参数与基线表逐项比对，找出被改动的那一项；参数无差异但现象仍在，就比较操作行为——是否在异常时段做过异常操作。这个顺序能把排查时间从几小时压到十几分钟。</p>

<h2>五、"售后跟进到底跟什么"</h2>
<p>跟进的价值不在态度，在可交付的动作：能不能换、多久换、换几次、换不好怎么办。这四条谈清楚，售后才有意义。</p>
<h3>把承诺换算成四个数字</h3>
<p>响应时限、换线时限、连续换线次数、退款触发条件。合理的组合是：30 分钟内响应、确认故障后 4 小时内换线、同一地址连续三次不可用可退款。没有数字的"跟进到底"只是话术。</p>
<h3>自营与转售在执行上的差别</h3>
<p>自营的换线是内部动作，几小时能完成；转售要向上一级申请，时限取决于上游排期。问一句"换线是你们直接操作还是提工单给上游"，比看任何宣传都准。</p>

<h2>常见问答</h2>

<h3>当天开通是不是所有地区都能做到？</h3>
<p>答：不是。热门城市在旺季常有售罄，自营池子也一样。可靠的做法是下单前先问目标城市当前库存，售罄就接受邻近城市或等一两天，别为了赶时间接受不匹配的地区，后面改起来更麻烦。</p>

<h3>"纯净"能不能用检测分数衡量？</h3>
<p>答：可以参考但不能只看分数。不同查询站的评分模型不一样，同一地址在 A 站 90 分、B 站 60 分很常见。更可靠的是四项硬指标：ASN 归属、同段已售数、公开记录、路径形态，四项都过才是真的干净。</p>

<h3>环境掉线算不算售后范围？</h3>
<p>答：通常不算，因为环境由使用方配置。但如果卖方交付的是整套环境包，且参数在未操作的情况下被重置，就属于交付质量问题，可以要求排查。下单前问清交付边界，能避免这类扯皮。</p>

<h3>连续换线几次还没解决，该怎么办？</h3>
<p>答：先确认换的是不是同段地址。同一 /24 里换来换去，问题不会消失。要求换到不同段、不同城市，并保留每次工单记录；三次仍不可用，按合同退款条款处理，同时评估是否需要更换供应商。</p>
